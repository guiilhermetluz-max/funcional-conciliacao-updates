# Funcional Conciliação — informações de atualização

Repositório público exclusivo para informar a **versão** do aplicativo Windows. 

O único arquivo necessário para a consulta anônima é `latest.json`.

**NÃO incluir aqui:** scripts, executáveis privados, planilhas `.xls` / `.xlsx`, dados de clientes, razões contábeis, resultados de conciliação, capturas de tela, tokens, chaves privadas ou logs internos.

Os arquivos do programa e a compilação permanecem no repositório **privado** `guiilhermetluz-max/funcional-conciliacao-clientes`. Esta área pública informa somente se há nova versão; não distribui o `.exe`.

Ao publicar nova versão, edite apenas os campos `version`, `published_at`, `notes` do manifesto. Não inclua URLs de repositórios privados como supostos downloads anônimos.
